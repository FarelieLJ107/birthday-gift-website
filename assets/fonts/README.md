# Fonts (opsional)

Secara default font dimuat dari Google Fonts (Playfair Display, Poppins, Caveat).
Jika ingin website 100% offline, unduh file .woff2 ketiga font tersebut ke folder ini
dan tambahkan `@font-face` di `css/style.css`. Tanpa internet, website tetap berjalan
dengan font cadangan (Georgia / system-ui / cursive).
